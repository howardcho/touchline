# Touchline training video narration

Voice: calm, clear female narrator. Current build uses the macOS Moira voice.

## 1. TOUCHLINE

Welcome to Touchline. In the next few minutes, you will learn every control you need to set up a rotation, run a session, change plans on the sideline, and review the final match report.

## 2. Choose a rotation

Start on the selection screen and choose two, three, four, or five teams. Two- and three-team sessions are free and unlimited. Four and five teams require the one-time Premium unlock. Each card also shows that team count’s saved colours, game time, and changeover time.

## 3. Save game defaults

Open Settings at the bottom of the selection screen. Defaults are saved separately for each team count. On the Game tab, choose five unique colours; smaller sessions use the first colours in that order. Set game and changeover durations from one second to twenty-four hours. You can also enable the five-second opening countdown. Save Defaults stores these choices on this device.

## 4. Control when play ends

The Session tab can set an end time for today. Hard Stop ends exactly on time and may shorten the final game if it meets your minimum. Finish Last Game allows a game started before the deadline to finish. Full Games Only starts only games that fit completely. Disable the end time for continuous rotation.

## 5. Choose every sound

On the Audio tab, the master switch controls timer sounds. Then enable or disable each cue: kickoff whistle, one-minute, thirty-second, and ten-second warnings, the full-time whistle, the five-to-one countdown, team callouts, and stadium crowd. Tap Test beside any cue to preview it. On supported phones, Touchline briefly ducks other audio so important announcements are clear.

## 6. Run the game

After choosing teams, the match board shows Now Playing and Up Next. Start begins the optional timer; the same button pauses and resumes it. Minus or plus thirty seconds adjusts only the current game or changeover. Restart Game restores the full game time and pauses, which is useful after a false start. The timer moves automatically through the changeover and into the next game.

## 7. Use the full-screen clock

Tap Maximize for the largest possible clock. The current teams stay above the timer, while Up Next remains visible in a compact position. Tap the same icon again to return to the full board. Keep Screen Awake helps prevent the display from sleeping while Touchline remains visible.

## 8. Jump to any game

Tap the Up Next card to jump there immediately, or open the list icon to see all upcoming games. The list includes every game that can start before the session end time; continuous sessions show one full rotation. Tap any listed game to play it next. Previous and Next also move manually, reset the timer, and leave it paused.

## 9. Change today’s plan

Session Timing changes game length, changeover length, the end time, finish rule, and minimum shortened game while play is underway. These are session-only changes, so your saved defaults remain untouched. The current phase keeps its remaining time, and new durations begin with the next phase.

## 10. Add or remove teams

Use minus Team or plus Team to change the roster between two and five teams. Choose the exact colour leaving or arriving. During play, the current game and changeover finish first, then Touchline begins a fresh rotation. Late arrivals do not need catch-up games, and a newly added colour applies only to this session.

## 11. Review the rotation

View Rotation and Fairness lists every matchup and explains the schedule. Touchline warns when a smaller rotation requires a back-to-back appearance. Complete cycles balance game counts, and every schedule loops automatically. The five-team cycle avoids consecutive appearances, including across the loop boundary.

## 12. Finish with a match report

Tap End Session, shown with the stop icon, and confirm when play is finished. Touchline records partial game time already played, then shows total session time, average playing time, games played, and each team’s playing time. Close the report to review the board, or return to selection for another session.

## 13. Premium and saved purchases

On Android, Premium is a one-time Google Play purchase that unlocks four- and five-team rotations. Use Restore Purchase if the same Google account already owns it. Your settings and active session are stored locally, and the native apps bundle their audio for offline use. That is everything you need to run Touchline to its fullest.
